# Starbucks Sales Dashboard

## Project Overview
A Power BI dashboard for analyzing
Starbucks sales data.

## Tools Used
- Power BI
- Power Query
- DAX
- CSV Datasets

## Key Features
- KPI Cards
- Beverage Category Analysis
- Sales Distribution
- Caffeine and Calorie Insights

## Project Files
- `Starbucks.pbix` - Final Power BI report file
- `starbucks.csv` - Main dataset containing drink nutritional values and categories
- `directory.csv` - Location dataset for store presence mapping
